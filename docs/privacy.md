# 隐私声明

Current standalone release (0.2.5): the extension calls the configured provider directly. Provider keys are stored locally in `chrome.storage.local`, without application-level encryption. Update checks send no provider credentials or course content. The older backend contract below is preserved for history and does not describe the current distribution.

**当前独立版补充（2026-10-20，v0.2.0）**：后端、控制台和数据库已从本发行仓库移除。题目与答案在运行内存处理，由扩展直接发往用户配置的供应商；API Key 按既有本地直连设计保存在本机 `chrome.storage.local`，没有应用级加密，不能沿用下文旧后端 AES-GCM 加密承诺。手动发送和自动运行启动授权的范围不同，课程自动模式按该次授权连续处理已适配任务。

更新下拉仅保存分发渠道与清单 URL；点击检查时请求具体更新源权限，获取公开版本、下载地址、说明及 SHA-256，不发送题目、答案、供应商 Key、Cookie 或本产品会话。没有后台轮询更新、静默安装、自动重载或更新遥测。更新源服务本身可看到正常网络连接信息，下载链接由浏览器打开；必须信任提供更新源的发布者。

**当前独立版补充（2026-10-21，0.2.8 M0 诊断与声音）**：运行页新增「复制诊断行」，用于在提交卡住或页面异常时安全地把结构化状态反馈给维护者。该行只包含结构性计数与简短枚举——文档数、iframe 数、cards 帧数与 `num` 是否存在、模块数、模块 kind、活动模块序号、异常计数、任务点标记「已完成/总数/不可读」计数、视频数与 `readyState/seekable/currentTime/duration/是否结束/是否暂停`、PDF 就绪布尔、可滚动候选数、提交候选数——外加运行状态计数（阶段、已完成数、各类跳过数）。诊断行**绝不包含**题干、选项、答案、解析、完整页面 URL、HTML、课程名称或标识、姓名学号、Cookie 或任何供应商 Key；这些字段也不进入 `TaskSnapshot.diagnostics`。声音告警可使用随扩展一起打包的本机音频文件（`apps/extension/sounds/`，构建时拷贝进 `dist/sounds/`），仅在浏览器本地解码播放，**不上传、不联网获取**；扩展页面 CSP 无 `media-src` 且 `connect-src` 仅指向后端，因此音频通过 `chrome.runtime.getURL` 直接播放而非 `fetch`，不会产生额外的对外网络请求。

本声明适用于本仓库实现的《学习通 AI 学习助手》：Chrome Manifest V3 扩展（以下简称“扩展”）、Web 配置控制台（以下简称“控制台”）与 Java 后端（以下简称“服务端”）。本文是实现与部署的隐私契约；具体部署实例的运营者信息、联系方式和数据保留政策应由运营者在部署页面补充，不得伪造。

## 1 核心结论（请先读）

1. **本方案不是零知识（Zero Knowledge），也不是端到端加密（E2EE）。** 服务端必须解密用户保存的供应商 API Key 才能调用供应商；运行中的服务端能够接触题文与密钥明文。
2. **“无第三方信息采集”不等于“题目不经过第三方”。** 用户点击发送后：
   - 本产品服务端会处理本次题目；
   - 用户选择的 AI 供应商会收到题目与必要提示词；
   - 如果用户配置的是 API 网关，网关也是数据处理方；
   - 供应商/网关的数据保留政策由用户自行确认，本产品无法替用户保证。
3. **题目与答案默认不在服务器落库。** 题文和答案只存在于本次调用内存与用户当前侧边栏中。
4. **不希望信任 SaaS 运营者的用户，可以自托管同一套后端。** 自托管时，运营者就是用户自己，但供应商/网关仍是第三方。

## 2 数据流

```text
学习通页面（用户当前标签页）
  → 扩展隔离世界页面脚本：只在用户点击“读取当前题目”后读取用户确认的单题容器
  → 扩展侧边栏：本次内存中预览、编辑
  → 用户点击“发送并生成解析”
  → 本产品服务端：校验 → 解密用户密钥 → 调用用户选定供应商
  → AI 供应商（或用户配置的 API 网关）
  → 返回答案 → 扩展侧边栏展示/编辑
  → 用户单次审核后：扩展在本地写入页面控件并回读验证
```

扩展的 Service Worker 只负责打开侧边栏、短时脚本注入和受控消息转发，不发送 AI 请求。AI 请求由保持打开的扩展可信页面直接发往用户配置的本产品后端。

## 3 不收集的数据（硬性约束）

产品代码与服务端**不得**收集、读取或传输：

- 学习通账号密码、Cookie、浏览记录；
- 完整页面 HTML、整页 `innerText`、隐藏字段；
- 姓名、学号、班级、完整课程信息；
- 用户全部标签页或与当前题目无关的页面内容；
- 页面 Local Storage / Session Storage 内容；
- 验证码答案或绕过访问控制所需的信息；
- 统计 SDK、广告、崩溃上报、隐藏遥测数据。

扩展不请求 `cookies`、`webRequest`、`debugger`、`<all_urls>`、`unlimitedStorage` 权限；不配置 `externally_connectable`，不注入远程代码。

## 4 服务端处理与保存的数据

### 4.1 允许保存

- 独立账号（用户名、BCrypt 密码散列、创建时间、状态）；
- 加密后的供应商 API Key（AES-256-GCM，主密钥通过只读 Secret 文件注入，数据库只保存密文、Nonce 与 `wrapping_key_id`）；
- 用户配置（Base URL、模型、协议、能力与生成参数）；
- 请求回执元数据：请求 ID、配置版本、状态、错误码、延迟、供应商返回的可用 Token 用量、提示词版本、用于幂等的 HMAC；
- 会话（不透明 Bearer Token 的 SHA-256 散列与到期时间）；
- 邀请码散列。

### 4.2 默认不保存

- 题干、选项、空格、答案、解析、完整提示词；
- 页面 HTML、页面 URL、DOM 定位器、页面指纹；
- 姓名、学号、课程名；
- 网站 Cookie；
- 供应商完整错误响应体。

题目与答案仅存在于调用内存和用户当前侧边栏中。关闭侧边栏会清除题目和答案，不持久化恢复。

### 4.3 保留期（默认值）

| 数据 | 默认保留 |
|---|---|
| 请求回执 | 7 天 |
| 应用日志 | 7 天，限制文件大小与轮转数量 |
| 数据库备份 | 7 天 |
| 登录会话 | 8 小时绝对有效期，不滑动延期 |
| 账号数据 | 用户主动删除账号后删除（见第 7 节） |
| 加密密钥 | 用户删除密钥或删除账号即删除；主密钥轮换按运维流程处理 |

保留期是默认配置，部署运营者可以在 `app.retention.*` 中调整；调整时应同步更新部署实例的隐私说明。

## 5 日志

允许记录：`requestId`、操作类型、状态、错误码、延迟。禁止记录：`Authorization`、API Key、密码、题文、答案、供应商原始响应体、完整用户导出内容。

服务端、反向代理与测试报告都必须遵守同一规则。生产关闭请求体日志与 HTTP 调试日志。外部遥测、崩溃上报与追踪服务默认完全关闭。

## 6 安全措施与边界

已实现/要求的安全措施：

- 供应商 API Key 使用 AES-256-GCM 加密；主密钥通过只读 Secret 文件注入，不进入数据库、镜像、源码或日志；AAD 绑定用户、配置、密钥版本与主密钥 ID。
- 修改 Base URL 时在同一事务内清除旧密钥与验证状态，旧密钥不会自动迁移到新域名。
- 登录使用不透明 Bearer Token，数据库只保存散列；控制台 Token 仅在内存，扩展 Token 放 `chrome.storage.session`（`TRUSTED_CONTEXTS`）。
- 服务端对供应商地址执行允许目录、连接阶段 DNS 校验、禁止自动重定向等 SSRF 防护；生产仅允许 HTTPS。
- 容器以非 root 用户运行、只读文件系统、Secret 文件挂载、禁用新提权能力。

无法承诺的边界：

- 服务端内存无法绝对清零；运行中的进程能够接触明文题文与密钥。
- 一旦数据已发送给供应商或网关，本产品无法撤回，也无法保证对方的保留政策。
- 浏览器扩展运行在用户浏览器的隔离世界，但页面本身与浏览器环境仍可能存在用户无法控制的风险；不要在不信任的页面输入敏感信息。
- 本产品不提供零知识、端到端加密、匿名网络或“绝对安全”的保证。

## 7 用户权利

- **访问/导出**：控制台提供“导出数据”，包含账号公开信息、配置公开字段与聚合用量；不包含密码散列、密钥密文、Nonce、会话散列或请求 HMAC。
- **更正**：可修改配置、模型、Base URL、密钥；可修改密码。
- **删除**：删除 API 配置、删除密钥、删除账号。删除账号会撤销全部会话并删除在线数据库中的关联数据；备份最长 7 天后自然过期，恢复备份时会重新应用删除清单。
- **退出**：退出登录删除当前会话；修改密码撤销全部会话。
- **限制**：已经发送给 AI 供应商的数据无法通过本产品撤回。

账号恢复通过部署运营者的本地运维命令完成，不设计基于未验证邮箱的找回流程。

## 8 使用边界与学术诚信

本产品用于学习辅助。以下行为被实现层面显式禁止：

- 自动提交考试、作业或计分测验；
- 伪造视频进度、学习时长或签到；
- 绕过网站的访问控制、验证码或只读限制；
- 在已识别为考试/计分的页面提供回填。

用户应遵守所在学校与学习通平台的使用规则。

## 9 自托管

用户可以在自己的服务器上部署同一套后端（见 `infra/` 与 README）。自托管时：

- 不再由 SaaS 运营者处理数据，但主机提供方、备份存储、AI 供应商与网关仍可能接触数据；
- 用户需自行管理主密钥、数据库备份、TLS 证书与访问控制；
- 本隐私声明中关于“非零知识”“供应商是处理方”“默认不落库”的说明同样适用。

## 10 第三方清单

| 第三方 | 何时接触数据 | 说明 |
|---|---|---|
| 用户选定的 AI 供应商 | 用户点击发送后 | 收到题目、选项、空格与必要提示词；保留政策由用户/供应商决定 |
| 用户配置的 API 网关 | 用户选择网关作为 Base URL 时 | 作为额外的数据处理方，可能记录请求 |
| 主机/云服务商与备份存储 | 部署时 | 存储加密后的密钥、配置、账号与回执 |
| 反向代理（如 Caddy） | 所有请求 | 只处理 TLS 与转发；配置要求不记录请求体与认证头 |

本产品不接入广告、统计、崩溃上报、题库采集或其他隐藏遥测服务。

## 11 变更

隐私版本号变更时，注册与发送请求需要用户重新确认新的隐私版本；服务端在不同意新版本时返回 `CONSENT_REQUIRED`。历史版本声明应保留在仓库中，不得静默改写。

## 12 与规格的一致性

本声明对应 `docs/architecture.md` §1.3、§20 与 `AGENTS.md` 的硬性约束。任何“无数据上传”“零知识”“完全匿名”“供应商零保留”等超出上述事实的表述都不得用于本产品宣传。

## 13 自动提交与讨论发表（2026-10-22）

The authorized runner submits verified quiz answers and publishes discussion replies to the bound Chaoxing course. Course/question modes use the selected provider for missing answers; videos-only submits existing complete answers/drafts without model calls. Discussion text and publication evidence remain in memory; no new credentials, telemetry or browser permissions are collected.

用户授权运行后，完整核验的测验答案与讨论回复会提交到当前绑定的学习通课程。刷课/刷题的缺答通过用户所选供应商生成；只刷课仅提交已有完整答案/草稿，不调用模型。讨论文字及发表核验证据仅在内存处理，不新增凭据采集、遥测或浏览器权限。

> 本文是工程隐私契约，不构成法律意见。面向终端用户的部署页面应补充运营者主体、联系方式、适用法域与投诉渠道。
