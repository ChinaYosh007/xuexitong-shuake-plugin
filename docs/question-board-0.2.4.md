# Question board and dual viewer / 签到表与双栏预览（0.2.4）

Both requested changes ship together: compact colored question numbers and a side-by-side Markdown/image viewer, plus removal of the extension's encoded-image size rejection.

题目清单用紧凑签到表取代逐题纵向卡片。绿色表示可靠源文字读取；蓝色表示依赖图片、原图或整题图片重试；红色表示最终未回填且需补答，优先于前两色。普通文字题仅额外附带渲染图不改变其绿色分类；预览读图不改变处理分类。补答核验成功后红色消失，恢复文字/图片分类，绿色本身不宣称作答/提交成功。

补答卡片也只保留统一的查看题目按钮，不再重复展开大图与题干。点击题号或该按钮打开原生dialog，左侧只显示可复制的Markdown源文本，右侧只显示完整题图，均独立滚动；可前后题切换、Esc/关闭、原尺寸切换、复制/下载图片。显示题文均为纯文本，不执行题目中的HTML。只读题图在打开时异步采集并复用同任务/指纹缓存；自动请求和回填继续运行。题目列表切换或指纹变化会关闭旧题窗口，旧指纹不匹配的图像不显示。题号附文/图/!和可访问标签，不只依赖颜色。

大图修复：合成图不再因编码超过400000字符拒绝；原图以PNG读取，不再为400000/460000字符预算反复有损编码/缩小。原图仅极大画布保留6400万像素、最长边16384的资源分配预算；合成图已有布局边界保留。匿名CORS、损坏/未加载图像、画布读取失败仍如实报告。独立版直连的Chat/Responses请求没有该字节上限；旧后端OpenAPI限额属于历史接口，未把未部署后端伪称已修改。供应商/浏览器自己的大小和内存限制不由扩展保证。

验证结果见验收§9.35。没有操作真实课程或请求真实付费模型。
