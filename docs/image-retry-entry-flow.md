# Whole-question image retry and entry / 整题图片重试与逐题录入（0.2.2）

Image retries now send the complete question and every supported option. The image-stage answer replaces earlier samples and is written directly when its answer fields map to the page. Each pending question shows model replies first, then two main actions: image retry/write and direct entry of the editable displayed answer.

## 当前行为

- 首次模型回答缺少上下文、看不清图片，或格式/答案不可用于本题时，自动生成新的完整题图（题干、程序、所有已支持选项），直接使用第二阶段图片回答。普通文字答案仅声明不确定时，原共识路径仍保留；第二阶段图片回答不再与旧答案投票。
- 选项列表复用已支持的 `.Zy_ulTop` 与主题 `ulTop` 变体；画面边栏标 `opt_1/opt_2`，防止只有图片或 CSS 字母的选项缺少映射依据。题图/原图读取、源数据中的图示检测和题目指纹覆盖同一内容根。
- 初次合成图失败时保留原图读取兜底；若只能得到首次文字参考答案，会再尝试完整题图，恢复后自动处理。整题图片无法生成时明确报告，不能假装第二阶段发过图片。
- 图片阶段即便带“不确定”说明也直接采用本次结果；但仍需完整 ANSWERED 答案、有效选项/空格ID并通过页面回读。NEEDS_CONTEXT/REFUSED/缺答没有可写入的答案，不能伪造内容。
- 强制图片请求不允许被 text-only 配置静默删图；需使用支持图像的模型并开启该能力。JSON 格式错误的有界纠正仍存在（最多3次），这是格式重试，不是和旧答案投票。

## 两个主要入口

待补答卡片先展示模型原始回答及候选，候选预填入下方输入区域，允许自行修改。

1. **采用图片重新发送并回写**：重新读取完整题干和全部选项，发送本次图片，展示新回答后直接回填核验。不和旧候选投票，不只发送一张孤立选项原图。
2. **一键录入本题**：写入下方当前答案，既可直接使用预填候选，也可自己填。仅核验本题，其他题可以稍后处理。

错误和成功显示在当前题旁；未填写、控件拒绝、题目变化、图片失败会明确说明。其余题的模型返回不清空已经编辑的草稿，同一编号进入另一任务或题目变化时不会沿用旧草稿。全部待答题核验通过后才自动提交、继续；任一缺答时不提交。高级批量录入/网页已填写核验收在折叠区，网页核验未检测完整答案时会列出题号。

## 修复的“没反应”根因

旧 `submitManual` 要求传入全部待补答题目，导致只想录入一题也被其他题的空答案阻止；旧草稿监听器在列表变化时清空全部草稿；网页核验无完整答案时没有明确反馈。现在允许待答列表的非重复子集，每题回读成功后更新状态；草稿按任务/指纹保留，仅删除过期项；输入、图片请求或回读失败会在当前题显示原因。ERROR 后仍可补答恢复，停止中的图片请求返回后不写入。

## 验证范围

新增合成图片选项 + 两道文字题，通过真实 MV3 扩展测试：初次需要图片、第二阶段即使说明不确定也选择图片结果；两张选项图均由本地绘图覆盖；独立图片按钮补第二题，第三题草稿不丢；空录入有错误，最后一题录入后提交/确认仅一次。上游是伪模型，没有把测试冒称真实供应商视觉识别成功。

单元回归覆盖整题模式跨协议传递、严格生成图、全部主题选项图片与ID标签、图片能力拒绝不发纯文字、逐题子集录入、图片失败、网页缺答、ERROR恢复、停止后不回填等。最终 **418单测、11契约单测、类型/构建、30/30 MV3浏览器测试通过**；0.2.2 ZIP共15条目/0.77MB，CRC/逐字节dist和说明/清单SHA-256核验通过。详见验收§9.33。

本轮未改用户真实课程、未请求真实模型，未新增权限或网络目的地，不绕过 CORS/只读/正式考试/题目变化守卫。页面嵌入媒体、图示损坏或跨域不允许读取时，保留明确失败与手动录入路径。

## 安装后

停止旧运行，覆盖原加载目录，重载扩展并刷新课程页，关闭旧调度页后新开。确认顶部 **v0.2.2**，重新读取题目；旧运行页不会自动换用新代码或修正旧缓存。
