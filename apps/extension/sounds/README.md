# 告警声音（0.2.8 §7）

运行出错、待人工补答或视频弹题作答失败时的声音提醒。播放优先级：**本目录音频文件 → 内置合成蜂鸣 → 仅文字提示**。

## 固定文件名（替换时保持同名）

| 触发场景 | 文件名（按 mp3 → wav → ogg 顺序尝试） | 当前状态 |
|---|---|---|
| 运行出错 / 弹题枚举失败（`popup-failed` 缺省时回退 `error`） | `error.mp3` | ✅ 已内置（19.1s，来自用户提供的抖音音频） |
| 待人工补答 | `needs-input.mp3` | 缺省 → 用合成蜂鸣 |
| 视频弹题失败（可单独指定） | `popup-failed.mp3` | 缺省 → 回退 `error` |

## 怎么换成你自己的音频

1. 把你的音频转成 `mp3 / wav / ogg` 任一格式，**改成上表对应的文件名**放进本目录即可。
2. 建议单文件 ≤1MB、总 ≤3MB。当前 `error.mp3` 为 272KB。
3. 构建时由 `scripts/build-extension.mjs` 的 `copySoundAssets()` 拷贝到 `dist/sounds/`（README 不拷贝）。
4. 重新构建：`npm run build`（或打包 `npm run package:extension`），再到 `chrome://extensions` 点“重新加载”。

## 隐私与限制

- 音频只随扩展打包在本机播放，绝不上传、不含任何题文/答案。
- 依赖“开始运行”按钮的用户手势解锁：在此之前浏览器可能挂起音频。
- Service Worker 无 `AudioContext`、`offscreen` 被禁用 → **关闭运行页就没有声音**。
- 运行页在后台被节流时文件音可能轻微抖动；合成蜂鸣走音频时钟预排程更稳。
- 想完全静音：运行页取消勾选“声音提醒”。
